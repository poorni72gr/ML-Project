1. What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence (AI) where computers learn from data to make predictions or decisions without being explicitly programmed.

Instead of writing rules manually, we train a model on data.

Example: Email spam detection, recommendation systems, image recognition.

2. How ML Works (Basic Workflow)

Collect Data: Gather raw data (e.g., images, text, numbers).

Preprocess Data: Clean and transform data for the model.

Choose a Model: Select an algorithm (e.g., Linear Regression, Decision Tree).

Train the Model: Feed data to the model so it learns patterns.

Evaluate: Test the model on new data to check accuracy.

Predict: Use the trained model to make predictions on new data.

3. Types of Machine Learning
a) Supervised Learning

Input data + known output (labeled data)

Goal: Learn a mapping from input → output.

Examples:

Predict house prices (Regression)

Email spam detection (Classification)

Common Algorithms:

Linear Regression, Logistic Regression, Decision Trees, Random Forest, SVM

b) Unsupervised Learning

Only input data (no labels)

Goal: Find patterns or structure in the data.

Examples:

Customer segmentation

Market basket analysis

Common Algorithms:

K-Means Clustering, Hierarchical Clustering, PCA

c) Reinforcement Learning

The model learns by trial and error using feedback (rewards or penalties).

Examples:

Self-driving cars

Game AI (like AlphaGo)
